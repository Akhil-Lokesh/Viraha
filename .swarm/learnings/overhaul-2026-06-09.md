# Learnings — overhaul wave (realtime + privacy + Keepsake redesign)

1. **Contract-first parallel waves work.** Backend and frontend agents ran concurrently against
   dictated API contracts (paths, envelopes, SSE event names). Zero contract mismatches in the
   endpoints themselves; the misses were *cross-cutting runtime behavior* no contract covered
   (EventSource bypasses axios interceptors; rate limiter counts SSE reconnects). Reviews must
   target the seams a contract can't express.
2. **Always lsof the port before a smoke test.** A stale dev server from a previous session held
   :4000 and silently served pre-overhaul code — every new route 404'd and it looked like the wave
   had failed. Kill/verify listeners first; don't debug "missing routes" before confirming which
   process answered.
3. **Token-contract for design systems.** Seven UI agents stayed visually coherent by consuming
   CSS variables with literal fallbacks (`var(--viraha-gold, #D4A843)`) defined by exactly one
   foundation agent. No ordering dependency, no theme-file collisions.
4. **Dictate exported symbol names across parallel agents.** server.ts agent imported
   `shutdownRealtime` from a module another agent was creating simultaneously — worked because the
   orchestrator prompt fixed the exact name/signature in both prompts.
5. **Reviewers self-correct if asked to verify.** R2 downgraded its own CRIT-1 to "unfounded" after
   checking JSON serialization; R1's NaN claim on place-stories radius was grep-refuted by the fixer.
   The "grep-verify before fixing" rule keeps paying for itself.
